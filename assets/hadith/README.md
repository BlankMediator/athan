# Optional hadith packs

17 collections, 51,776 source records. See [source comparison, matching rules, coverage and rebuild instructions](../../docs/hadith-data-sources.md).

`manifest.json` lists compressed packs, checksums, pinned sources and input hashes. `quality-report.json` records missing fields and removed exact duplicates. Source licences and reuse notices are retained alongside the packs. Do not describe source translations as CC0: the CC0 notice covers the Open Hadith Data structure and retains translation rights.

The reader displays the source text without paraphrasing. Missing grades, translations and chapter mappings remain explicit; Musnad Ahmad is partial. No API key is required.
