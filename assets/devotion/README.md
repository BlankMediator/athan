# Devotional texts

The displayed collection is the complete **Hisnul Muslim (Fortress of the Muslim)**: 132 chapters and 268 entries, including 75a and 75. `hisn/edition.json` retains Arabic, English meanings, transliteration where present, instructions, references and a Sunnah.com URL for every entry. It was extracted from the supplied majmoo-io repository's bundled Sunnah.com snapshot, pinned to revision `8786672f2a89115f13d5a27765066378993bd358`. Licence: `hisn/LICENSE-AGPL-3.0.txt`; provenance: `hisn/source-metadata.json`. Rebuild with `scripts/build-hisn.py` from the pinned archive or retained source snapshot. Source wording remains Arabic/English when the interface language changes.

Legacy selection material (no longer displayed): Arabic, English meanings, transliteration, notes and source references are retained from [Fitrahive dua-dhikr](https://github.com/fitrahive/dua-dhikr), commit `f42f895f914319a844c3e3c2279483cae060ea19`, retrieved 2026-09-15. The MIT licence is included as `LICENSE-fitrahive.txt`. The five original English JSON files are in `source/`. Unreviewed benefits/virtues fields are not displayed; no new promises or grading claims are added. Missing or unnumbered references remain labelled as supplied rather than guessing a number.

The daily hadith collection contains 12 individual narrations with **original Arabic and the published English translation**, including narrator context. Wording is preserved from each linked Sunnah.com page; only HTML markup and whitespace are normalized. `hadith-sources.json` records source URLs and content hashes. Rebuild using `scripts/build-daily-hadith.py` and the retained individual page snapshots in `tmp/sources`. Sunnah.com permits selected narrations for didactic presentation; see https://sunnah.com/about#reproduction. Notifications use the same source wording, and opening a reading shows the complete narration and reference.

Readings rotate deterministically by the selected location's local date. Daily dua reminders use the general repentance and remembrance chapters (129/130), so morning/evening-specific wording is not sent at an unrelated time. Both reminder types default to off.
